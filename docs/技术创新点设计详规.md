## T1. AEBG（Argument-Evidence Bipartite Graph）

### 1.1 问题动机

现有的质量守门（Moderator `_quality_gate`）基于简单的启发式：
- 论点是否与已有论点重复（embedding 余弦相似度 > 0.85）
- 论点是否跑题（关键词覆盖率检查）
- 是否超过 token 上限

这些规则是**负向过滤**——只能排除「看起来很糟」的论点，无法评分「这个论点有多好」。

**AEBG 的思路**：辩论中的每个论点都建立在证据之上。我们把「论点引用了哪些证据」显式建模为一张二部图，然后用标准图算法（度数、PageRank、社区结构）**评分**论点质量。这是一个**正向评分**机制，同时保留了原有的负向过滤。

### 1.2 形式化定义

设：
- **E** = { e₁, e₂, ..., e_m }：Phase 0 构建的证据集合
- **A** = { a₁, a₂, ..., a_n }：Phase 1 中辩方提出的论点集合
- 每条论据 a_i 携带一个引用集合 **refs(a_i)** ⊆ E（a_i 明确引用的证据）
- 构建二部图 **G = (V, X)**，其中 **V = E ∪ A**，**X = { (a_i, e_j) | e_j ∈ refs(a_i) }**

每条边 (a_i, e_j) 可以带权重 w_ij，例如：
- w_ij = evidence.confidence × evidence.relevance（证据条目本身的质量）
- 或 w_ij = 1（无权图，简单版）

### 1.3 评分算法（4 个指标 + 合并）

```python
# 伪代码：AEBG 评分
# 输入：argument（Pydantic 模型，含 .evidence_refs 字段）
#      graph（networkx.Graph 对象，已包含所有证据节点）
# 输出：Dict[str, float]，四个评分 + 综合分

def score_argument(argument, graph, emb_provider):
    arg_id = f"arg_{argument.id}"
    graph.add_node(arg_id, type="argument", text=argument.text)

    # 添加边：论点 ↔ 被引用的证据
    cited_evidence = [e for e in evidence_brief.items
                      if e.id in argument.evidence_refs]
    for ev in cited_evidence:
        graph.add_edge(arg_id, f"ev_{ev.id}",
                       weight=ev.confidence * ev.relevance)

    # --- 指标 1：证据支撑度 ---
    # 度数 / 图中最大度数（论点引用了多少不同证据）
    deg = graph.degree(arg_id, weight="weight")
    max_deg = max(d for _, d in graph.degree(weight="weight")) or 1
    evidence_support = deg / max_deg     # ∈ [0, 1]

    # --- 指标 2：证据多样性 ---
    # 被引用证据在语义空间中的离散程度（embedding 平均两两距离）
    if len(cited_evidence) >= 2:
        embs = np.array([emb_provider.encode(ev.text)
                         for ev in cited_evidence])
        sim_matrix = embs @ embs.T          # 对称矩阵，对角线=1
        iu = np.triu_indices(len(cited_evidence), k=1)
        mean_sim = float(sim_matrix[iu].mean())
        evidence_diversity = 1.0 - mean_sim  # ∈ [0, 1]
    else:
        evidence_diversity = 0.0             # 仅引用 0-1 条证据 → 无多样性

    # --- 指标 3：Personalized PageRank（权威度） ---
    # 以高置信度证据节点为"权威源"，论点越靠近这些源 → 得分越高
    personalization = {
        node: (data.get("confidence", 0.5)
               if data.get("type") == "evidence" else 0.0)
        for node, data in graph.nodes(data=True)
    }
    pagerank_scores = nx.pagerank(
        graph, personalization=personalization, alpha=0.85, max_iter=200
    )
    # 归一化：把 PPR 映射到 [0, 1]
    max_pr = max(pagerank_scores.values()) or 1.0
    pagerank_norm = pagerank_scores[arg_id] / max_pr

    # --- 指标 4：证据闭包可达性 ---
    # 检查是否存在"高置信度证据邻居"（置信度 >= 0.75）
    high_conf_neighbors = [n for n in graph.neighbors(arg_id)
                           if graph.nodes[n].get("confidence", 0) >= 0.75]
    total_neighbors = len(list(graph.neighbors(arg_id))) or 1
    closure_reach = len(high_conf_neighbors) / total_neighbors

    # --- 综合评分 ---
    # 等权合并；未来可以用贝叶斯优化学习权重
    combined = 0.25 * evidence_support + 0.25 * evidence_diversity \
             + 0.30 * pagerank_norm       + 0.20 * closure_reach

    return {
        "evidence_support": round(evidence_support, 4),
        "evidence_diversity": round(evidence_diversity, 4),
        "pagerank": round(pagerank_norm, 4),
        "closure_reach": round(closure_reach, 4),
        "combined_score": round(combined, 4),
    }
```

```python
        return ("ACCEPT", "MARGINAL_QUALITY")
    else:
        return ("ACCEPT", "GOOD_QUALITY")
```

## T2. DPP 多样性约束（Determinantal Point Process）

### 2.1 问题动机

多 Agent 辩论中常见「回音室效应」——反方反复重述相同论点，没有真正的多样性。DPP 是一个优雅的数学工具，它**同时建模「质量」和「多样性」**：

- 一个候选集合 S 的 DPP 概率 ∝ det(L_SS)，其中 L 矩阵由「候选质量 × 候选间负相似度」构成
- 行列式 det(L_SS) 在「元素质量高」且「元素间差异大」时取最大值

对于我们的单元素选择（每轮从 K 个候选中选 1 个），DPP 简化为：选择使 `quality(i) · (1 − similarity(i, 历史论点))` 最大的候选 i。

### 2.2 简化版算法（推荐先实现）

```python
# 文件：src/debate/dpp_sampler.py
# 简化版：贪心选择质量 × 与历史不相似度 最大的候选
# 数学上这等价于 |S|=1 的 DPP greedy selection

class DPPArgumentSampler:

    def __init__(self, lambda_: float = 1.0, num_candidates: int = 3):
        self.lambda_ = lambda_        # 多样性强度
        self.num_candidates = num_candidates  # 每轮生成的草案数
        self.history_embs = []        # 已选中论点的 embedding 历史

    def sample(self,
               candidates: List[Argument],
               quality_scores: List[float],  # 来自 T1 AEBG 的 combined_score
               candidate_embs: np.ndarray) -> int:
        """
        返回选中候选的 index (0..num_candidates-1)
        """
        n = len(candidates)
        if n == 0:
            raise ValueError("没有候选论点")

        if not self.history_embs:   # 第一轮：直接选质量最高的
            return int(np.argmax(quality_scores))

        # 计算每个候选与历史的最小相似度（与最相似历史论点的距离）
        history_matrix = np.array(self.history_embs)   # (H, D)
        sim_to_history = candidate_embs @ history_matrix.T  # (n, H)
        max_sim_to_history = sim_to_history.max(axis=1)    # (n,)

        # DPP 简化评分：quality * exp(−λ · max_sim_to_history)
        # intuitively：高质量且与历史最不相似的得高分
        scores = np.array(quality_scores) * \
                 np.exp(-self.lambda_ * max_sim_to_history)

        chosen = int(np.argmax(scores))

        # 把选中的论点加入历史
        self.history_embs.append(candidate_embs[chosen])

        return chosen

    # --- 降级方案（不需要 embedding 时的纯文本版） ---
    def sample_rejection(self,
                          candidates: List[Argument],
                          quality_scores: List[float],
                          theta_sim: float = 0.70) -> int:
        """
        拒绝采样：找到第一个与所有历史论点的 BLEU/ROUGE 相似度 < theta 的候选
        如果全部失败，则回退到质量最高者。
        """
        for i in np.argsort(-np.array(quality_scores)):  # 按质量降序
            candidate_text = candidates[i].text
            max_sim = max(
                self._text_similarity(candidate_text, hist)
                for hist in self.history_texts
            ) if self.history_texts else 0.0
            if max_sim < theta_sim:
                self.history_texts.append(candidate_text)
                return i
        # 全部被拒绝 → 退化为质量最高者
        best = int(np.argmax(quality_scores))
        self.history_texts.append(candidates[best].text)
        return best

    @staticmethod
    def _text_similarity(a: str, b: str) -> float:
        # Jaccard 相似度（基于 unigram set）
        set_a, set_b = set(a.split()), set(b.split())
        if not set_a or not set_b:
            return 0.0
        return len(set_a & set_b) / len(set_a | set_b)
```

```python
        self.dpp_sampler = DPPArgumentSampler(lambda_=1.0, num_candidates=3)

    def generate_argument(self, context, brief, coach_hint):

                      for _ in range(self.dpp_sampler.num_candidates)]

        # --- 变化点 2：计算每个候选的 AEBG 质量评分 ---

        # --- 变化点 3：DPP 选择 1 个 ---
        chosen_idx = self.dpp_sampler.sample(
            candidates=candidates,
            quality_scores=quality_scores,
            candidate_embs=candidate_embs,
        )
        return candidates[chosen_idx]
```

## T3. KS 检验辩论收敛检测

### 3.1 问题动机

标准 MAD 做法：固定 8 轮自由辩论。但实际观察到：
- **简单问题**：2–3 轮后正反双方已就关键事实达成共识，继续辩论只是重复 → 浪费 token
- **复杂问题**：8 轮不够，仍在演进 → 提前停止会丢失有用内容

**KS 检验的直觉**：让 5 位法官在每轮辩论后对当前论点质量做一次轻量级打分（5 维向量）。如果连续两轮的打分分布「没有显著差异」（KS 检验 p-value > 0.05），说明辩论已收敛——正反双方都没有提出新观点。

### 3.2 算法实现

```python
# 文件：src/debate/stability.py

import numpy as np
from typing import Tuple, Optional, List
from scipy.stats import ks_2samp


class DebateStabilityDetector:
    """
    使用 Kolmogorov-Smirnov 检验检测辩论评分分布是否收敛。
    核心思想：如果两轮的评分分布没有显著差异（p > α），
              说明正反双方没有提出能改变评分的新论点 → 可以停止。
    """

    def __init__(self,
                 alpha: float = 0.05,     # 显著性水平（默认 0.05，无需调参）
                 min_rounds: int = 3,     # 至少辩论多少轮才能停止
                 max_rounds: int = 8,     # 最多不超过多少轮（硬上限）
                 variance_ratio: float = 0.05):  # 方差辅助信号：若方差降至初始的 5%
        self.alpha = alpha
        self.min_rounds = min_rounds
        self.max_rounds = max_rounds
        self.variance_ratio = variance_ratio
        self.history: List[np.ndarray] = []  # 每轮一个 5 维评分向量
        self._initial_std: Optional[float] = None

    def record(self, judge_scores: np.ndarray) -> None:
        """
        每轮辩论后调用。
        judge_scores: shape=(5,), 五位法官的轻量打分（0–100 的整数即可）
        """
        assert judge_scores.shape == (5,), "需要 5 位法官的 5 维评分"
        self.history.append(judge_scores.copy())
        if len(self.history) == 1:
            self._initial_std = float(judge_scores.std())

    def should_stop(self) -> Tuple[bool, Optional[float]]:
        """
        返回 (是否应停止, 本轮 KS 检验的 p-value)
        """
        n = len(self.history)

        # 规则 1：尚未达到最小轮次 → 继续
        if n < self.min_rounds:
            return False, None

        # 规则 2：达到硬上限 → 停止
        if n >= self.max_rounds:
            return True, None

        # 规则 3：KS 检验——最近两轮的评分分布
        latest = self.history[-1]
        previous = self.history[-2]

        # 处理退化情形：两轮完全相同（KS 统计量=0, p=1.0）
        if np.array_equal(latest, previous):
            return True, 1.0

        try:
            ks_stat, p_value = ks_2samp(latest, previous)
        except ValueError:
            # scipy 的 ks_2samp 在某些极端情形下可能报错
            return False, None

        # p 值大 → 不能拒绝"分布相同"的原假设 → 辩论已收敛
        if p_value > self.alpha:
            return True, float(p_value)

        # 规则 4（辅助信号）：方差显著下降
        if self._initial_std and self._initial_std > 0:
            current_std = float(latest.std())
            if current_std / self._initial_std < self.variance_ratio:
                return True, float(p_value)

        return False, float(p_value)

    # --- 诊断工具：返回收敛摘要（用于 process_metrics 日志） ---
    def summary(self) -> dict:
        return {
            "n_rounds_recorded": len(self.history),
            "latest_p_value": (None if len(self.history) < 2
                                else float(ks_2samp(
                                    self.history[-1],
                                    self.history[-2])[1])),
            "score_trend": [float(v.mean()) for v in self.history],
            "score_std_trend": [float(v.std()) for v in self.history],
        }
```

```python
    def run_free_debate(self, coach, speakers_pro, speakers_con, brief):

            # ... 正反双方交替发言 ...

                current_arguments, round_idx
```

### 3.4 「轻量打分」的 Prompt 设计

```
你是一名辩论评审。请对以下论点给出一个 0–100 的整数评分，
不提供任何解释文字。评分标准：
  90–100: 引用充分且高质量证据，推理严密，对问题有重要贡献
  70–89:  有合理证据支撑，推理基本正确，但缺少深度
  40–69:  观点可接受但证据薄弱，或推理有瑕疵
   0–39:  无证据支撑或存在明显逻辑错误

[论点文本]
"{argument_text}"

[你只需输出一个整数]
```

> **为什么只给整数分？** 降低 token 成本。5 位法官 × 每轮 ~50 tokens = 250 tokens / 轮，比写完整判决书便宜 ~8×。而且 KS 检验只关心「分布是否变化」，不需要高精度。

```
  断言：detector 在达到 max_rounds=8 时返回 True

用例 3：min_rounds 保护
  输入：仅 2 轮相同评分
  断言：虽然两轮分布相同，但轮数 < 3 → 返回 False

用例 4：方差辅助信号
  输入：第 1 轮方差大（[10, 90, 20, 80, 50]，std ≈ 34）
        第 2 轮方差小（[58, 62, 60, 61, 59]，std ≈ 1.5）
  断言：variance_ratio = 1.5/34 ≈ 0.044 < 0.05 → 返回 True
        （即使 KS p-value 略低于 0.05 也会停）
```

## T4. DS 证据理论融合（Dempster-Shafer Evidence Fusion）

### 4.1 问题动机

现有 Final-Judge 使用简单加权平均：`final_score = Σ w_i · score_i`。问题：
- **丢失分歧信息**：法官 A=90、法官 B=10 和 法官 A=50、法官 B=50 的加权平均都是 50，但前者代表严重分歧，后者代表一致同意
- **没有不确定性估计**：下游使用者不知道「这个判决是法官一致同意的，还是激烈分歧后的折中？」

**DS 证据理论**把每位法官看作一个「独立证据源」，每位法官不仅给出评分，还给出「我对这个评分的置信度是多少」（即基本概率指派 BPA）。然后用 **Dempster 合成规则**合并多个证据源，得到同时包含「最终评分」、「系统不确定性」和「置信区间」的结果。

### 4.2 算法实现

```python
# 文件：src/judgment/ds_fusion.py

import numpy as np
from typing import List, Dict, Optional, Tuple


class DSEvidenceFusion:
    """
    基于 Dempster-Shafer 证据理论的多法官评分融合。

    核心：
      1. 把 0–100 的连续评分离散化为 n_levels 个档位
         （默认 10 档，每档 10 分：5, 15, 25, ..., 95）
      2. 每位法官 = 一个高斯型 BPA（基本概率指派）
         BPA 是一个 (n_levels + 1) 维向量
         前 n_levels 维 = 分配到各档位的置信质量
         最后一维 = m(Θ) = 分配给"完全无知"的质量
      3. 用 Dempster 合成规则顺序合并所有法官的 BPA
      4. 从合成 BPA 计算期望得分/不确定性/置信区间
    """

    LEVEL_CENTERS = np.array([5, 15, 25, 35, 45, 55, 65, 75, 85, 95],
                             dtype=float)  # 固定 10 档

    def __init__(self,
                 n_levels: int = 10,
                 uncertainty_threshold: float = 0.40):
        self.n_levels = n_levels
        self.level_centers = np.linspace(5, 95, n_levels)  # 0–100 均匀分档
        self.uncertainty_threshold = uncertainty_threshold

    # ---- 核心：单个法官到 BPA 的转换 ----
    def _gaussian_bpa(self,
                       score: float,           # 0–100 原始评分
                       sigma: float,           # 法官对自己评分的 ±σ（如 15）
                       weight: float           # 该法官的重要性权重 0–1
                       ) -> np.ndarray:
        """
        构建一个高斯型 BPA：
          m({score_k}) ∝ weight · exp(-(level_k - score)² / (2σ²))
          m(Θ) = 1 − weight  （即：法官保留的"无知度"）
        """
        # 1) 高斯核 → 各档位的概率质量
        diffs = self.level_centers - score
        mass_on_levels = np.exp(-diffs**2 / (2 * sigma**2))

        # 2) 归一化 + 乘以 weight → 得到"有观点的部分"
        mass_on_levels = mass_on_levels / mass_on_levels.sum() * weight

        # 3) 最后一维是 m(Θ) = 无知度
        bpa = np.zeros(self.n_levels + 1)
        bpa[:self.n_levels] = mass_on_levels
        bpa[self.n_levels] = 1.0 - weight
        return bpa

    # ---- 核心：Dempster 合成规则 ----
    @staticmethod
    def _dempster_combine(bpa1: np.ndarray, bpa2: np.ndarray) -> np.ndarray:
        """
        合并两个 BPA（按定义实现，复杂度 O(n_levels²)，n≤10 足够快）

        数学定义：
          (m1 ⊕ m2)(A) = (1/K) · Σ_{B∩C=A} m1(B)·m2(C)
          其中 K = 1 − Σ_{B∩C=∅} m1(B)·m2(C) （归一化冲突质量）

        对我们的单点+Θ 简化模型，B、C 只能是 {level_k} 或 Θ。
        """
        n = bpa1.shape[0] - 1  # level 数
        assert bpa2.shape[0] == n + 1

        combined = np.zeros(n + 1)

        # 非空交集情况：
        #   {i} ∩ {i} = {i}       → bpa1[i] * bpa2[i]
        #   {i} ∩ Θ   = {i}       → bpa1[i] * bpa2[Θ]
        #   Θ   ∩ {i} = {i}       → bpa1[Θ] * bpa2[i]
        #   Θ   ∩ Θ   = Θ         → bpa1[Θ] * bpa2[Θ]
        for i in range(n):
            combined[i] = (bpa1[i] * bpa2[i]
                           + bpa1[i] * bpa2[n]
                           + bpa1[n] * bpa2[i])

        combined[n] = bpa1[n] * bpa2[n]  # Θ ∩ Θ

        # 归一化（K = 非空交集总质量）
        total = combined.sum()
        if total < 1e-6:
            # 所有法官给出的评分完全不相交（极端冲突）
            # 退化为"完全无知"：m(Θ) = 1
            combined[:] = 0.0
            combined[n] = 1.0
        else:
            combined /= total

        return combined

    # ---- 对外接口：融合 N 位法官 ----
    def fuse(self,
             judge_scores: List[float],
             judge_confidences: Optional[List[float]] = None,
             judge_weights: Optional[List[float]] = None
             ) -> Dict[str, float]:
        """
        融合多位法官的评分。

        参数:
          judge_scores: List[float]，长度 = N（如 5），每维 0–100
          judge_confidences: 每位法官对自己评分的 ±σ，默认全 15
          judge_weights: 每位法官的重要性，默认均等权重

        返回:
          {
            "final_score": float,                # 期望得分，0–100
            "uncertainty": float,                # m(Θ)，0–1
            "confidence_interval_lo": int,       # 80% 置信区间下界
            "confidence_interval_hi": int,       # 80% 置信区间上界
            "needs_human_review": bool,          # uncertainty > 阈值时 True
            "conflict_mass": float,              # 融合过程中的总冲突度（诊断用）
          }
        """
        n_judges = len(judge_scores)
        if judge_confidences is None:
            judge_confidences = [15.0] * n_judges
        if judge_weights is None:
            judge_weights = [1.0 / n_judges] * n_judges

        # Step 1：每个法官 → BPA
        bpas = [
            self._gaussian_bpa(score, sigma, weight)
            for score, sigma, weight in zip(judge_scores,
                                             judge_confidences,
                                             judge_weights)
        ]

        # Step 2：顺序合并（Dempster 合成满足结合律，顺序不影响最终结果）
        combined = bpas[0]
        total_conflict = 0.0
        for next_bpa in bpas[1:]:
            # 在合并前估算冲突（1 − 非空交集的总质量 = 归一化前的空集质量）
            # 简单做法：先做一次未归一化合并，看冲突部分的大小
            # （为简洁起见，此处用简化估计：最高和最低分数差 / 100）
            combined = self._dempster_combine(combined, next_bpa)

        # Step 3：从合并后的 BPA 计算输出
        level_probs = combined[:self.n_levels]

        # 3a) 期望得分
        final_score = float(np.sum(level_probs * self.level_centers))

        # 3b) 不确定性 = m(Θ)
        uncertainty = float(combined[self.n_levels])

        # 3c) 80% 置信区间：从最可能的档位开始累加，直到累积概率 ≥ 0.80
        sorted_indices = np.argsort(-level_probs)  # 降序
        cumulative = 0.0
        included_levels = []
        for idx in sorted_indices:
            cumulative += level_probs[idx]
            included_levels.append(int(self.level_centers[idx]))
            if cumulative >= 0.80:
                break
        ci_lo, ci_hi = min(included_levels), max(included_levels)

        # 3d) 冲突度诊断：分数范围（max − min）作为粗略冲突估计
        conflict_mass = (max(judge_scores) - min(judge_scores)) / 100.0

        return {
            "final_score": round(final_score, 1),
            "uncertainty": round(uncertainty, 3),
            "confidence_interval_lo": ci_lo,
            "confidence_interval_hi": ci_hi,
            "needs_human_review": uncertainty > self.uncertainty_threshold,
            "conflict_mass": round(conflict_mass, 3),
        }
```

```python
class FinalJudge:

    def __init__(self, ...):
        self.ds_fusion = DSEvidenceFusion(n_levels=10,
                                          uncertainty_threshold=0.40)

    def synthesize_verdict(self, problem, debate_summary,
                            five_judge_reports):
        # 提取 5 位法官的结构化评分
        # （假设每位法官报告都有 .score 和 .confidence 字段）
        scores = [r.score for r in five_judge_reports]          # 0–100
        confidences = [r.confidence for r in five_judge_reports]  # ±σ

        # DS 融合（取代原来的加权平均）
        result = self.ds_fusion.fuse(
            judge_scores=scores,
            judge_confidences=confidences,
            # 权重：问题类型自适应（来自 T2 的学习权重或经验权重）
            judge_weights=self._weights_for(problem.type),
        )

        # 构造裁决报告
        verdict = JudgmentReport(
            final_score=result["final_score"],
            uncertainty=result["uncertainty"],
            confidence_interval=(result["confidence_interval_lo"],
                                 result["confidence_interval_hi"]),
            needs_human_review=result["needs_human_review"],
            reasoning_chain=self._build_reasoning_chain(
                five_judge_reports, debate_summary
            ),
            process_metrics={"ds_conflict_mass": result["conflict_mass"]},
        )
        return verdict
```

```python
# src/debate/moderator.py —— v1.2 的 run() 方法核心逻辑

class Moderator:
    def __init__(self, ...,
                 enable_aebg=True, enable_dpp=True,
                 enable_ks_stability=True):
        self.aebg = (ArgumentEvidenceBipartite(evidence_brief, emb_provider)
                     if enable_aebg else None)
        self.dpp_sampler = (DPPArgumentSampler(lambda_=1.0, num_candidates=3)
                            if enable_dpp else None)
        self.stability = (DebateStabilityDetector(alpha=0.05,
                                                   min_rounds=3,
                                                   max_rounds=8)
                          if enable_ks_stability else None)

    def run_debate_round(self, argument_candidates):
        # --- DPP 选择（T2） ---
        if self.dpp_sampler:
            q_scores = [self.aebg.score_candidate(c)
                        if self.aebg else [0.5]*len(argument_candidates)]
            chosen_idx = self.dpp_sampler.sample(argument_candidates,
                                                  q_scores,
                                                  candidate_embs)
            argument = argument_candidates[chosen_idx]
        else:
            argument = argument_candidates[0]  # 退化：选第一个

        # --- AEBG 评分（T1） ---
        if self.aebg:
            arg_metrics = self.aebg.add_argument(argument)
            self.process_metrics["aebg_scores"].append(arg_metrics)

            # 质量守门：如果评分过低则标记警告但仍允许通过辩论（不丢弃，
            # 因为法官会自行评价）
            if arg_metrics["combined_score"] < 0.30:
                self.warnings.append(
                    ModeratorWarning(type="LOW_EVIDENCE_QUALITY",
                                     message=f"combined_score = "
                                             f"{arg_metrics['combined_score']:.2f}")
                )

        # --- KS 检验收敛（T3） ---
        if self.stability:
            judge_light_scores = self._lightweight_judging(argument)
            self.stability.record(judge_light_scores)
            stop, p_value = self.stability.should_stop()
            self.process_metrics["ks_pvalues"].append(p_value)
            if stop:
                return "STOP_DEBATE"  # 触发 Phase 1 提前结束

        return "CONTINUE"
```

## 7. 已知的设计权衡与未来改进方向

| 决策 | 我们的选择 | 替代方案 | 权衡 |
|:---|:---|:---|:---|
| AEBG 权重 | 等权合并 4 项指标（0.25/0.25/0.30/0.20） | 贝叶斯优化学习权重 | 简单但可能非最优；权重学习需要标注数据 |
| DPP 候选数 | K=3 | K=1（不启用）或 K=5 | K 越大 token 开销越高；K=3 在质量和成本间平衡 |
| KS α | 0.05（经典统计标准） | 0.01 或 0.10 | α 越小 → 越保守（停得越晚）→ 多用 token |
| DS n_levels | 10 | 5 或 20 | 档位太少会丢失精度，太多会让 BPA 过度分散 |
| 法官置信度 σ | 默认全 15 分 | 让 LLM 自行报告 σ | 让 LLM 报告自身置信度是开放问题，效果不稳定 |

### 7.1 未来改进方向（不包含在 v1.2 范围内）
